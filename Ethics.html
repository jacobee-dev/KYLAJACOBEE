Ethics & Attribution

This page explains the resources used on this website and how visitor information is handled.

Sources & Licenses

The website was created using standard HTML, CSS, and optional vanilla JavaScript. No copyrighted images, commercial fonts, or paid templates are required.

Website Resources

  • HTML: Standard HTML5 markup.
  • CSS: Original stylesheet created specifically for this website.
  • JavaScript: Original simple form validation code.
  • Icons: Unicode emoji characters used for simple visual elements. No external icon files are used.
  • Images: No third-party images are used on this version of the website.
  • Fonts: System fonts are used. No external font service is required.

Privacy Statement

Green Community respects the privacy of website visitors. This website does not intentionally collect personal information for tracking or advertising purposes.

  • No tracking cookies are used.
  • No advertising trackers are installed.
  • No analytics software is installed.
  • No personal information is sold or shared for advertising.
  • The contact form is only a demonstration interface.

If this website is later connected to a real email or database service, users should be informed about what information is collected and how it will be protected.

Responsible Website Use

This website follows basic ethical web practices by providing accessible content, using descriptive labels, avoiding unnecessary tracking, and clearly identifying third-party resources when they are used.
